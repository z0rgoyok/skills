## Карта файлов и символов

Перечислить точную рекомендуемую карту каждого файла, которого касается разрешённое действие. Макс предварительно исследует репозиторий настолько, чтобы не перекладывать проектирование на исполнителя, и помечает неподтверждённые детали как предположения. Обнаруженный во время coding локальный факт может обосновать внутреннее отклонение по правилам ниже.

| Действие | Точный путь | Владелец | Что написать или изменить | Типы, функции, поля и exports | Связи и imports | Основание или предположение | Закрывающий тест |
|---|---|---|---|---|---|---|---|
| create | `path/to/file` | module | ... | ... | ... | ... | ... |
| edit | `path/to/file` | module | ... | ... | ... | ... | ... |
| delete | `path/to/file` | module | причина удаления | удаляемые symbols | consumers, которые обновить | ... | ... |
| leave unchanged | `path/to/file` | module | защищаемый контракт | ... | ... | ... | regression |
